# Castelei

Plataforma de estudos que ensina o conteúdo **e** a linguagem da prova.
Cada lição tem 3 camadas: explicação humana, como cai na prova e pegadinhas.

O planejamento completo (planos, fases, wireframes, identidade visual e
fundamentos científicos) está em [`docs/planejamento.md`](docs/planejamento.md).

## Stack planejada

- Frontend: Next.js (PWA)
- Backend: Laravel (API REST)
- Banco: PostgreSQL

## Status

Fase de planejamento. Código do MVP ainda não iniciado.
